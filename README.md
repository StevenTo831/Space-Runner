  Space Runner
This is the name I decided to go with for this project.
Like my original proposal stated, I've made an arcade-based game where you control a spaceship
 with your mouse to dodge obstacles hurtling towards you.

My major change was that I did not make a moving path the ship had to follow. However, I was able 
 to make an infinite scrolling backdrop, which I was very satisfied with.
 Additionally, I decided to add a feature that creates another debris dropper when you pass the 
 previous high score. This tree also spawns in different obstacle sprites.
 Furthermore, I created a new scene that acts as the Title and main menu, with more mellow music.

For audio, I stayed with my plan to have a background sound as you play the game, but I also added
 a crashing sound when you hit one of the obstacles, and sound when you pass the high score.
